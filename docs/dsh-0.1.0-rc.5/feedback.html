反馈为什么必须分版本

DSH 仍处于 Developer Preview。插件、命令、界面和运行时行为都可能随版本变化，因此一条讨论只有在能确认版本时，才会进入对应版本页。

本页只对应 v0.1.0-rc.5。 如果原帖没有版本信息，只会列为待确认线索，不会直接改写本版本的架构说明。以后出现新的 DSH 版本时，会建立新的社区反馈页和独立时间线。

时间戳与核查规则

  1. 原帖时间来自社区页面；如果平台只公开相对时间，不推算或伪造精确时刻。
  2. 收录时间记录本站完成阅读和归档的时刻，使用带时区的时间戳。
  3. 纳入时间只在反馈确实改变某页说明后记录，并链接到对应文档。
  4. 原帖被删除或修改时，保留状态说明，不把无法复核的内容继续当作事实。
