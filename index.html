BEFORE THE MAP / DSH 是什么

DeepSeek Harness：
把模型接到真实环境的 Agent 运行壳

模型负责判断下一步；Harness 负责让这一步安全、可追踪地发生。DSH（DeepSeek Harness）是 DeepSeek AI 开源的 Agent Harness：它组织会话与上下文，把模型接到工具、权限、沙箱、文件系统和界面，并记录运行过程。它最特别的设计是——这些能力连同 Agent Loop 本身，全部由插件组成，由 Cordis 负责动态组合与生命周期。
