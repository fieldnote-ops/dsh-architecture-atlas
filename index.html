DSH / 一个完整专题

DeepSeek Harness：
把模型接到真实环境的 Agent 运行壳

模型负责判断下一步；Harness 负责让这一步安全、可追踪地发生。DSH（DeepSeek Harness）是 DeepSeek AI 开源的 Agent Harness。它组织会话与上下文，把模型接到工具、权限、沙箱、文件系统和界面，并记录运行过程。在 DSH 里，这些能力连同 Agent Loop 本身都是插件；Cordis 根据配置和服务依赖安排它们的激活与卸载。

04 / LIVE CONTEXT

运行中的 agent，是 ctx 上的一组活键

Session、Tools、LLM 和 Agent Loop 等服务都挂在同一个 Context 上。Agent Loop 也能替换。

Γ∞ Context shared runtime

模型、工具、会话和循环通过 Context 互相发现。它们不依附于一个固定核心。

    一次对话，穿过六个架构时刻

    06 / MECHANISM LAB

    三件事，让插件真的可以被替换

    可替换的插件需要三项保证：效果可撤销、依赖变化能响应、更新失败能恢复旧状态。
